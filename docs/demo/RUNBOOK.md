**What to show:** Items are versioned, structured, convention-driven

Get-ChildItem ./fabric-src -Directory

**Expected output:**
```

----                 -------------         ------ ----
d----  2026-06-26    12:00 AM               lakehouse_fabricgsd_dev_001.Lakehouse
d----  2026-06-26    12:00 AM               nb_fabricgsd_dev_weu_001.Notebook
```

Then inspect the `.platform` metadata file:

```powershell
Get-Content ./fabric-src/lakehouse_fabricgsd_dev_001.Lakehouse/.platform | ConvertFrom-Json | ConvertTo-Json
```

**Key message:**

> Each item has a `.platform` metadata file that tracks:
> - Item type (Lakehouse, Notebook, etc.)
> - Display name
> - Logical ID (for Fabric REST API)
>
> This metadata is part of Fabric's Git integration standard. We version
> it alongside item definitions, making promotion repeatable.

## Demo 4 - Inspect Notebook Transformation Logic

**What to show:** AI-generated notebook that reads demo data and calculates metrics

```powershell
# Show file
Get-Content ./fabric-src/nb_fabricgsd_dev_weu_001.Notebook/notebook-content.py | Select-Object -First 50
```

**Narrate:**
> This notebook was generated by Copilot, anchored in GSD context. It implements 
> a medallion-style transformation:
>
> 1. Bronze: Load sales.csv (raw data)
> 2. Silver: Enrich with Revenue, Cost, Margin calculations
> 3. Gold: Aggregate by Region/Product for BI consumption
>
> Calculations:
> - Revenue = Quantity × UnitPrice
> - Cost = Quantity × EstimatedCostPrice
> - Margin = Revenue - Cost
> - MarginPercentage = (Margin / Revenue) × 100, or 0 if Revenue = 0

**Key message:**

> The notebook is part of version control. Changes go through Git reviews, 
> not via clicking in Fabric UI. We maintain audit trail and approval gates.

## Troubleshooting

| Issue | Resolution |
|-------|-----------|
| `validate-repo.ps1`: Item folder name invalid | Rename to `[Name].[ItemType]` (e.g., `sales.Lakehouse`) |
| `validate-repo.ps1`: Missing `.platform` | Create `.platform` with metadata.type, metadata.displayName, config |
| `deploy-bulk-import.ps1`: Environment vars not set | Export `FABRIC_TENANT_ID`, `FABRIC_CLIENT_ID`, etc., or update `deployment.parameters.json` |
| Notebook syntax errors | Validate notebook with Fabric Python kernel or `python -m py_compile notebook-content.py` |
| Real deployment permissions | Ensure Fabric workspace has Contributor role for service principal |
